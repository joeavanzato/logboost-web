```python
# gunicorn.conf.py — All Gunicorn settings for LogBoost Web
# Loaded via: gunicorn --config gunicorn.conf.py app:app

import os

# Worker configuration
# workers=1 is MANDATORY — SQLite cannot handle concurrent write locks from multiple processes
# threads=4 provides concurrency within the single process via gthread worker class
workers = 1
threads = 4
worker_class = "gthread"

# Timeout configuration
# MUST exceed the LogBoost subprocess timeout (300s in app.py run_logboost())
# If gunicorn timeout < subprocess timeout, gunicorn kills the worker mid-enrichment
timeout = 310
graceful_timeout = 30

# Network binding — 0.0.0.0 required for Docker port mapping
bind = "0.0.0.0:5000"

# Logging — stdout/stderr for Docker log collection (per user's locked decision)
# "-" directs output to stdout (access) and stderr (error)
accesslog = "-"
errorlog = "-"
loglevel = os.environ.get("LOGBOOST_LOG_LEVEL", "info").lower()

# Process naming (visible in docker exec ps output)
proc_name = "logboost-web"
```

Note: loglevel reads from LOGBOOST_LOG_LEVEL env var with "info" default — this connects the env var documented in .env.example to actual gunicorn behavior.

Create `Dockerfile` in the project root. Single-stage build per user's locked decision.

```dockerfile
FROM python:3.12-slim

# Metadata
LABEL maintainer="logboost" \
      description="LogBoost Web - Flask frontend for LogBoost enrichment engine"

# System dependencies in a stable layer (rarely changes, preserves pip cache)
# curl: required for HEALTHCHECK
# build-essential: required for iocextract's regex C-extension compilation
RUN apt-get update && apt-get install -y --no-install-recommends \
    curl \
    build-essential \
    && rm -rf /var/lib/apt/lists/*

# Create non-root user with home directory
# Home dir required for tldextract cache (~/.cache/python-tldextract/)
# UID 1000 per user's locked decision
RUN useradd --no-log-init --create-home --uid 1000 logboost

# Working directory
WORKDIR /app

# Layer caching: copy requirements first, install, then copy code
# Only rebuilds pip layer when requirements.txt changes
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# Pre-warm tldextract Public Suffix List cache
# Avoids first-request latency and PermissionError if network unavailable at runtime
RUN python -c "import tldextract; tldextract.extract('example.com')"

# Copy application source (filtered by .dockerignore allowlist)
COPY . .

# Set ownership of app directory to non-root user
RUN chown -R logboost:logboost /app

# Create directories for uploads and output (writable by logboost user)
# These may be overridden by volume mounts in Phase 2
RUN mkdir -p /app/uploads /app/output && chown -R logboost:logboost /app/uploads /app/output

# Pre-create the admin database file so health check passes on first boot
# sqlite3.connect() auto-creates the file; this ensures it exists before container starts
# The DB path must match the LOGBOOST_DB_PATH default below
RUN python -c "from admin import get_db; get_db().close()"

# Default environment variables — all have sensible defaults per user's locked decision
# Container works out of the box; override via env vars or .env file
ENV SECRET_KEY=dev-placeholder-change-me-in-production
ENV FLASK_ENV=production
ENV LOGBOOST_PATH=/usr/local/bin/logboost
ENV MAXMIND_DIR=/data/maxmind
ENV THREAT_DB_DIR=/data/intel
ENV LOGBOOST_LOG_LEVEL=info
ENV LOGBOOST_DB_PATH=/app/logboost_admin.db

# Switch to non-root user (after all root-required operations)
USER logboost

# Health check — curl hits /health endpoint
# --interval=30s: per user's locked decision (30-second interval)
# --timeout=10s: health response should be fast
# --start-period=30s: gunicorn + Flask import warmup time
# --retries=3: mark unhealthy after 3 consecutive failures (90s sustained)
HEALTHCHECK --interval=30s --timeout=10s --start-period=30s --retries=3 \
    CMD curl -f http://localhost:5000/health || exit 1

# Document the exposed port (still need -p in docker run)
EXPOSE 5000

# Run gunicorn with config file (NEVER python app.py — that uses Flask dev server with debug=True)
CMD ["gunicorn", "--config", "gunicorn.conf.py", "app:app"]
```

Key points to verify during implementation:
- build-essential is in a SEPARATE stable layer from pip install (preserves layer caching per user's priority)
- COPY requirements.txt BEFORE COPY . . (layer caching optimization)
- USER logboost comes AFTER all RUN commands that need root
- ENV SECRET_KEY has a deterministic dev default (NOT os.urandom — sessions survive restarts)
- HEALTHCHECK uses curl (per user's locked decision, curl is installed in apt layer)
- `RUN python -c "from admin import get_db; get_db().close()"` comes AFTER `COPY . .` (needs admin.py) and BEFORE `USER logboost` (needs write permission)
- ENV LOGBOOST_DB_PATH=/app/logboost_admin.db provides the default path — Plan 01-02 will make admin.py read from this env var
